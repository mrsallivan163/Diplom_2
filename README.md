## Дипломный проект. Задание 2: API-тесты

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers
- Сервис заказа бургеров - [Stellar Burgers](https://stellarburgers.nomoreparties.site/)
- Документация API - [API Stella Burgers](API_documentation/API_Stella_Burger.pdf)

### Реализованные сценарии

- Создание уникального пользователя
- Создание пользователя, который уже зарегистрирован
- Создание пользователя с незаполненными одним из обязательных полей
- Логин под существующим пользователем
- Логин с неверным логином и паролем
- Изменение данных пользователя с авторизацией/без авторизации
- Создание заказа с авторизацией/без авторизации
- Создание заказа с ингредиентами/без ингредиентов
- Создание заказа с неверным хешем ингредиентов
- Получение заказов конкретного пользователя авторизованного/неавторизованного

### Структура проекта
- `config` - пакет, содержащий эндпоинты провяеряемых методов и тестовые данные
- `tests` - пакет, содержащий тесты, разделенные по классам
- `utils` - пакет, содержащий вспомогательные методы
- `tmp` - временные данные
- `tmp/allure_report` - отчет Allure

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

### Очистить отчет Allure, запустить все тесты из директории tests и создать отчет новый Allure
> `$ rm -rf tmp/allure_report && pytest --alluredir=tmp/allure_report`

### Посмотреть отчет в веб версии пройденного прогона
> `$ allure serve tmp/allure_report`
